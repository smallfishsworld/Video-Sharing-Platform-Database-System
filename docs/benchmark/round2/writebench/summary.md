# WriteBench, round 2

Generated by `python3 scripts/writebench/tables.py` from the runs in this directory; each `<label>.json` holds the run's options, jar sha256, commit and boot, and `<label>.log` its output. WriteBench (`scripts/writebench/WriteBench.java`, run by `scripts/writebench/run.sh`) loads the service classes of one runner jar into a fresh JVM, recreates the `public` schema from that version's SQL, imports the benchmark data through the jar's `DatabaseService` and calls the services as the benchmark does. "Original" is the 2023 implementation (the course submission on `main`), "this version" the round-2 jar (42004a16) of this repository's benchmark runs, "round 1" the code at `978fe40` (stress mode only).

Every run held `/home/user/work/bench.lock` for its whole duration and released it afterwards; the original and this version alternate. Steady runs: `--settle` (a `CHECKPOINT` after the import), 300 warm-up and 600 measured calls per operation, 8 deletions of imported videos, seeds 1-5; the 8-client runs leave out `deleteAccount`, which has runs of its own (20 warm-up and 100 measured calls, seeds 1-3). Count mode: 20 calls per operation. Stress mode: 45 trials per part. Reads mode: 5 passes, seeds 1-3. Run `delacct-new-c8-r2` was interrupted once and run again from the start; the stopped attempt is not kept.

Every run was on the same boot (`uptime -s` gave the same time for all of them; each run's JSON records it).
